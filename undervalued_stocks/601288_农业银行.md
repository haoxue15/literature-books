# 农业银行（601288）投资分析

更新日期：2026-08-11

价格基准：2026-08-10收盘价6.46元

投资期限：3—5年

结论：**当前合理但安全边际不足，暂不进入推荐排序；合理价值约5.8—7.5元，基准约6.5元。现价约0.80倍2026年一季度普通股PB、8.3倍2025年EPS，反向隐含约8.8%的长期ROE，低于2025年的10.16%和一季度年化10.59%，但并未给净息差、零售不良及地产风险留下很厚折价。全年每股股息0.2495元对应3.86%回顾收益率，也低于多家更便宜银行。县域存款、庞大客户基础和近300%拨备覆盖率是真实优势；房地产不良率5.40%、个人经营贷和信用卡不良上升、核心一级资本一季度降至10.80%则限制估值。5.5元以下重新进入可分批研究区，6.46元以等待为主。**

## 估值快照：好银行不等于好买点

2025年末普通股BVPS为7.91元；一季度末股东权益3.303万亿元，扣除少数股东权益及4700亿元其他权益工具后，估算归属于普通股股东权益约2.827万亿元，对应BVPS约8.08元。6.46元对应PB约0.800倍。

2025年归母净利润2910.41亿元、增长3.18%，基本EPS为0.78元，现价PE约8.3倍。全年每10股分红2.495元，普通股现金分红873.21亿元，占EPS口径利润约32%，现价股息率3.86%。它是稳定收益来源，但并不足以单独抵消银行信用周期和估值下修。

农业银行H股8月10日收5.89港元；按近期约0.87人民币/港元粗略折算约5.12元，A股溢价约26%。两地普通股经济权利基本相同，A股流动性、投资者结构及人民币交易便利可以解释部分价差，却不应被当作内在价值。A股投资者需要比只看A股历史PB更严格。

2021—2025年归母利润复合增长约4.8%，而营收复合增速仅约0.2%。利润持续增长主要依靠资产规模、非息收入、信用成本和税负等共同支撑，不能把它理解成核心收入持续扩张。同期ROE下降1.41个百分点，净息差下降84个基点，银行价值创造能力仍在受低利率环境挤压。

2025年营业收入增长2.08%，利息净收入下降1.91%；手续费及佣金净收入增长16.57%，其他营业收入增长24.55%，信用减值损失下降2.79%。代理、托管和市场业务改善了收入结构，但金融投资增长17.9%至16.32万亿元、占总资产33.4%，意味着债券利率、信用和公允价值变化对报表的影响越来越大。

2026年一季度营收增长10.49%、利息净收入增长7.55%、手续费收入增长7.85%，净利润增长4.80%，收入修复明显。不过信用减值损失由570.60亿元增至737.19亿元、增长29.2%，增幅远快于收入；新增拨备吸收了相当部分收入增长。净息差1.26%仍比2025年低2个基点，尚不能确认盈利拐点。

一季度总资产增长4.60%、贷款增长4.97%、存款增长5.72%，扩表较快；年化ROE仅比2025年略升。若依赖资产规模对冲息差，而核心资本增长落后于风险加权资产，长期每股价值未必随总资产同步增长。

## 县域护城河：低成本负债与政策责任并存

农业银行拥有8.96亿个人客户、2.76亿手机银行月活客户和超过2.3万个境内网点，其中县域网点占多数。广覆盖形成稳定个人存款、结算和代销基础，是其相较股份行难以复制的负债端优势。2025年个人存款20.76万亿元，占境内存款主体；一季度个人存款再增至21.98万亿元。

2025年县域贷款10.94万亿元、增长11.0%，约占境内贷款41%；一季度增至11.77万亿元、单季增长7.65%。惠农e贷年末1.84万亿元、增长22.9%，普惠贷款4.35万亿元。规模、数据和线下触点提高获客效率，也让农业银行承担更强的乡村振兴、普惠和政策传导职责。

这种定位并非无成本护城河。县域、农户、小微及重点项目贷款定价受到政策目标影响，网点和人员体系使2025年成本收入比由34.40%升至35.18%。贷款增长快于存款或市场化负债占比上升时，低成本存款优势可能被部分抵消。

2025年同业存放和拆入资金增长27.0%至6.39万亿元，卖出回购由6157亿元升至1.45万亿元，已发行债务证券增长21.9%至3.26万亿元；这些市场负债增长显著快于客户存款7.7%。资产扩张不是完全由低成本存款驱动，需持续跟踪负债结构和流动性成本。

## 资产质量：总量改善，内部迁移不可忽略

2025年不良贷款3434.56亿元、不良率1.27%，关注贷款3776.15亿元、关注率1.39%；逾期贷款3395.47亿元、逾期率1.25%，低于不良率，认定口径较审慎。贷款减值准备超过1万亿元，拨备覆盖率292.55%、贷款拨备率3.71%，整体缓冲厚。

但不良率下降包含贷款分母增长，不良余额仍增加212.91亿元。尤其损失类贷款由558.40亿元升至1414.57亿元，增加856亿元；不良结构向最差等级迁移，不能只看总不良率下降3个基点。

对公贷款不良率由1.58%降至1.37%，改善较明显。房地产公司贷款8743.10亿元、占公司贷款5.6%，不良率仍为5.40%，不良余额471.97亿元，是对公不良中最大单一行业；批发零售不良率由2.32%升至2.44%。交通运输、水利公共设施等大行业改善，但其中可能含政府和大型项目信用支持，估值不应视为完全商业化风险。

个人贷款不良率从1.03%升至1.34%，不良余额从912.11亿元升至1242.87亿元、增长36.3%。住房贷款不良率由0.73%升至0.92%，信用卡由1.46%升至1.88%，个人经营贷由1.39%升至1.85%；仅个人消费贷由1.55%降至1.46%。个人经营贷余额增长19.9%，风险与扩张同步上升，是未来信用成本的主要变量。

重组贷款由1055.10亿元增至1339.66亿元、增长27.0%，约占贷款0.49%。2025年核销927.69亿元，同时第三阶段贷款准备重新计量增加1464.31亿元。厚拨备支持风险处置，但也表明资产质量改善需要持续清收、核销和重新计量，而非风险自然消失。

金融投资16.32万亿元，约为贷款的60%。贷款拨备覆盖率不能覆盖债券和其他金融资产的全部市场及信用风险；应同时观察摊余成本债券、其他债权投资的阶段迁移、地方政府相关敞口和利率敏感性。

## 资本、分红与普通股口径

2025年末其他权益工具4700亿元，包括800亿元境内优先股及多期无固定期限资本债。普通股股东对利润和权益的索取权排在这些工具之后，因此本报告使用披露的普通股BVPS和EPS，而不是用3.24万亿元总权益直接除以普通股数。

核心一级资本充足率由2024年11.42%降至2025年11.08%，一季度进一步降至10.80%；一级资本充足率由13.63%降至12.97%、再降至12.61%。总资本充足率仍有17.40%，但核心资本趋势弱于总资本，说明扩表依赖二级资本和其他一级资本支持。

2025年风险加权资产增长9.8%，普通股权益约增长6.9%；一季度资产和贷款单季增长接近5%。若未来继续用高增速扩表对冲低息差，资本约束可能限制分红率提升。3.86%的股息率尚不足以把资本补充和摊薄风险视为无关紧要。

## 压力后剩余收益估值

采用`合理PB=（长期ROE－长期增长率）/（股权成本－长期增长率）`，先对8.08元普通股BVPS施加信用压力折扣。估值不把国家控股或系统重要性直接变成股东无风险价值；政府支持更可能保护存款和金融稳定，不保证普通股估值。

| 情景 | 账面压力折扣 | 长期ROE / 股权成本 / 增长 | 每股价值 |
|---|---:|---:|---:|
| 悲观 | -8% | 6.0% / 11.5% / 1.0% | 约3.5元 |
| 基准 | -2% | 9.0% / 10.5% / 2.0% | 约6.5元 |
| 乐观 | 0% | 10.2% / 9.8% / 2.5% | 约8.5元 |

悲观情景假设地产、个人经营贷、信用卡和金融投资导致普通股权益永久损失约2260亿元，长期ROE降至6%；基准情景假设净息差在低位企稳，规模和非息收入使长期ROE维持9%；乐观情景要求一季度收入修复持续、信用成本回落且资本效率稳定。

按悲观25%、基准55%、乐观20%加权，结果约6.2元。考虑县域负债、拨备和分红确定性，合理区间取 **5.8—7.5元**，基准约6.5元。现价相对基准仅约1%，不足以承担尾部信用风险和A/H价差，因此当前不列为“值得买”。

## 强制反向估值

反向一：0.800倍PB在10.5%股权成本、2.0%长期增长下，隐含长期ROE约 **8.80%**。这比2025年低1.36个百分点，市场计入继续下滑，但没有计入极端衰退；若长期ROE只能维持8%，合理PB约0.706倍、价值约5.7元。

反向二：若长期ROE维持基准9.0%，合理PB约0.824倍。现价相当于先把BVPS由8.08元削减至7.84元，仅隐含约840亿元、3%的普通股权益永久损失，远低于3435亿元不良贷款和1339.66亿元重组贷款的表面规模。厚拨备可吸收大部分风险，但这一隐含损失缓冲仍不宽。

反向三：0.2495元股息按10.5%股权成本、2.0%永续增长折现约2.94元。现价其余3.52元依赖约68%的留存利润持续创造高于股权成本的增量价值；若扩表后ROE降到8%以下，留存的价值会明显下降。

反向四：若投资者要求现价提供20%基准安全边际，基准价值需要达到8.08元，接近不施压BVPS本身。这要求合理PB约1倍，即长期ROE接近10.5%的股权成本；当前经营ROE可以接近，但净息差和核心资本趋势尚不足以保证长期维持。

## 优势、风险与价格纪律

优势：全国最大县域金融网络之一；个人客户和存款基础庞大；不良认定较审慎；拨备超过万亿元；对公不良下降；县域、普惠、科技和绿色贷款带来规模增长；手续费收入修复；系统重要性和融资能力强；分红连续稳定。

主要风险：净息差长期下降；资产增速快于核心资本；市场化负债增长；个人经营贷、信用卡和按揭风险上升；房地产不良率高；损失类贷款显著增加；重组和核销规模大；金融投资占比高；政策性目标可能压低风险定价；普通股之前有4700亿元其他权益工具；A股较H股溢价；现价股息率不够高。

分类：**历史第四批第58名完成深度更新；当前价格合理但安全边际不足，暂不进入新的全局推荐排序，累计跟踪数不重复增加。**

| 股价 | 判断 |
|---:|---|
| 4.5元以下 | 接近悲观与基准情景之间，先排查系统性信用事件 |
| 4.5—5.5元 | 安全边际较强，可分批研究 |
| 5.5—5.8元 | 有一定安全边际，适合小步分批 |
| 5.8—6.8元 | 合理价值附近，现价所在区间，以等待为主 |
| 6.8—7.5元 | 合理偏高，需盈利修复确认 |
| 7.5元以上 | 需长期ROE稳定在10%以上且风险下降支撑 |

## 失效条件与下一报告期跟踪

若不良率升破1.55%、关注率升破1.8%、拨备覆盖率跌破240%、个人贷款不良率升破1.8%、房地产不良率升破6.5%、核心一级资本充足率跌破10.3%、正常化ROE连续两期低于8.5%，或分红率因资本约束显著下降，应下调估值并暂停加仓。

下一报告期重点核对净息差、存款成本、市场化负债占比、个人经营贷与信用卡不良、住房贷款、房地产和地方相关敞口、损失类与重组贷款、信用减值、金融投资阶段迁移、核心一级资本、风险加权资产、县域贷款定价及中期分红。

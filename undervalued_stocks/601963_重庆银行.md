# 重庆银行（601963）投资分析

更新日期：2026-08-11  
价格基准：2026-08-10 A股收盘价10.97元；H股收盘价7.99港元  
投资期限：3—5年  
结论：**A股暂不入选，合理价值约10.5—13.0元、基准约11.8元，9.5元以下才有较明确安全边际；H股折算价格明显更低，可在汇率、税费和流动性适配时优先比较。2025年营收和归母利润均增长约10.5%，不良、关注和逾期率同步下降，2026年一季度继续双位数增长，基本面优于静态低PB叙事；但A股约0.67倍最新PB、核心一级资本充足率仅8.67%，还有可转债摊薄。A股较H股人民币折算价溢价约五成，已经吃掉大部分基本面折价。**

2021—2023年收入和净息差明显下行，2024年收入止跌，2025年利息净收入增长22.44%至124.59亿元，带动营收和归母利润分别增长10.48%和10.49%；净息差回升4个基点、ROE升至9.50%。手续费净收入下降32.66%、投资及公允价值收益下降21.95%，但信用减值损失增长20.99%，说明利润增长并非单纯少提拨备。

一季度收入、归母利润分别增长11.57%和10.40%，不良率再降2个基点，信用减值损失增长约30%。这是三家重庆/贵州区域银行中当前增长最好的一家。

一季度普通股BVPS 16.39元，A股10.97元对应PB约0.669倍；2025年归母利润对应约6.7倍PE。2025年中期每股0.1684元、末期每股0.2797元，全年合计0.4481元，A股股息率约4.08%。

## 资产质量、资本与摊薄

2025年末不良率1.14%、关注率1.94%、逾期率1.36%，分别下降0.11、0.70和0.37个百分点；拨备覆盖率升至245.58%。公开指标显示风险在改善，而非用关注类堆积维持低不良。

但资产扩张很快：2025年总资产增长20.67%突破万亿元，2026年一季度再增约7.2%。一季度核心一级资本充足率8.67%、一级资本充足率9.71%、资本充足率12.57%，虽较年末略升，却明显低于渝农商行和沪农商行。持续高速扩表需要利润留存、可转债转股或外部资本补充。

“重银转债”仍在转股期。估值应使用稀释每股收益并跟踪转股数量；转股可改善核心资本，却会摊薄现有股东BVPS和EPS。低资本缓冲使乐观增长与每股价值增长并非同一回事。

银行覆盖重庆及四川、陕西、贵州，区域比贵阳银行略分散，但重庆相关贷款和地方信用仍是主轴。年报未用可比口径完整披露地方平台贷款，不能用“不良率下降”替代对化债利率、展期和行业集中度的检查。

## 压力剩余收益估值

以一季度BVPS 16.39元为起点，使用稳定期剩余收益关系并加入账面损失与可转债摊薄折扣。

| 情景 | 账面/摊薄折扣 | 长期ROE / Ke / g | 每股价值 |
|---|---:|---:|---:|
| 悲观 | -12% | 6.5% / 12.0% / 1.0% | 约7.2元 |
| 基准 | -5% | 9.0% / 11.0% / 1.5% | 约12.3元 |
| 乐观 | 0% | 11.0% / 10.0% / 2.0% | 约18.4元 |

鉴于核心资本较薄、扩表快和A/H价差，本报告不取模型中点，给出A股合理区间 **10.5—13.0元**、基准约11.8元。现价仅比基准低约7%，不够补偿尾部风险；H股7.99港元按约0.91人民币/港元粗略折算约7.3元，接近悲观价值，跨市场相对吸引力明显更高。

## 强制反向估值

反向一：A股0.669倍PB，在11%股权成本、1.5%长期增长下，隐含长期ROE约 **7.85%**。它低于2025年9.50%，但差距不足以称为极端悲观。

反向二：按基准长期ROE 9%，合理PB约0.789倍。A股只提供约15%的PB折价；若把5%潜在信用与转债摊薄先扣除，基准价值约12.3元，安全边际仍薄。

反向三：A股10.97元相对H股人民币折算价约溢价50%。即使考虑A股流动性、税制和投资者结构差异，如此价差仍意味着A股投资者为相同普通股经济权益支付显著更高价格。

## 分类与价格纪律

分类：**A股暂不入选；历史第四批第39家公司完成深度更新，累计公司数不增加，不占推荐名次。**

| A股价格 | 判断 |
|---:|---|
| 8.0元以下 | 接近压力价值，可在资本改善时积极复核 |
| 8.0—9.5元 | 有安全边际，可分批研究 |
| 9.5—10.5元 | 合理偏低 |
| 10.5—13.0元 | 合理价值区间；现价在区间内 |
| 13元以上 | 依赖高增长和顺利转股 |

失效条件：核心一级资本充足率跌破8.3%、不良率重新升破1.4%、关注率升破2.5%、净息差再度低于1.3%，或可转债导致每股价值增长明显落后于总利润增长。

重点跟踪资本充足率、转股进度与稀释、贷款与风险加权资产增速、关注及逾期率、重庆平台化债利率、净息差、信用成本和A/H溢价。

## 筛选方法

各批次均侧重“大概率不会因一次预测错误而永久亏损”的公司：

1. 最近五年持续盈利，核心业务可理解；
2. 资产负债表或资本充足水平足以承受行业低谷；
3. 有真实现金回报，包括分红、回购或稳定自由现金流；
4. 使用适合行业的估值方法后，基准情景仍有安全边际；
5. 反向估值显示，当前价格隐含的长期预期足够保守。

银行采用剩余收益/合理 PB 模型，保险采用内含价值与营运利润，周期股使用中周期利润，制造与消费公司使用 FCFF、正常化盈利及股息收益率交叉验证。没有用单一低市盈率作为买入理由。

## 组合使用建议

- 不要一次性买完：可将计划仓位分成 3—5 份，按价格和财报进展投入。
- 单只股票不宜超过股票资产的 10%；银行、保险、家电等同类风险敞口也应设置合计上限。
- 核心仓优先从 S/A 级选择；B 级降低仓位，C/C+ 级只适合作为等待验证的逆向小仓。
- 不要把中国平安与中国太保、招商银行与宁波银行、三家白电公司同时当作充分分散，它们内部仍有明显的共同宏观风险。
- 每次年报和半年报后重做估值。股价进入各报告的“观察/减仓区”时，不应再沿用买入结论。

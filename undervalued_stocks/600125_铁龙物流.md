# 铁龙物流（600125.SH）投资分析

> 数据截止：2026-08-13；财务数据截止2026年一季度（未经审计），完整年度数据截止2025年（经审计）。价格采用2026-08-12上交所完整交易日不复权收盘价 **5.52元**。金额若无特别说明均为人民币。

## 结论与估值快照

**结论：5.52元属于“中度低估”，但只适合作为低增长、防守型候选，不是高确定性成长股。** FCFF三情景给出的价值为 **3.15 / 6.40 / 10.10元**，概率加权约 **6.33元**，合理区间取 **5.8—7.0元**。基准值较现价有约16%上行空间，概率加权安全边际约13%；低于通常要求的25%深度价值门槛，因此宜等待 **5.0元附近** 才有更舒服的买入赔率。

## 业务质量与五年趋势

公司的核心资产不是账面占营收近六成的贸易，而是铁路特种集装箱和沙鲅铁路。2025年供应链管理业务贡献62.84%收入、毛利率仅0.96%；特种箱业务收入27.20亿元、毛利率26.97%，却贡献72.21%毛利。特种箱保有量增至15.3万只，具备国铁网络、专业箱谱系和客户协同壁垒；沙鲅铁路连接哈大铁路与鲅鱼圈港，设计运能已扩至8,500万吨/年。优点是核心资产难复制、资产负债表稳健，弱点是增长受铁路政策、大宗商品货运和国企资本配置约束。

五年营收大幅波动主要来自低毛利供应链贸易，不能把营收下降直接等同于核心业务衰退。2025年营收下降11.69%，归母净利反增37.48%，部分源于毛利结构改善，也有2024年1.15亿元资产减值损失低基数；2025年资产减值仅0.04亿元。因此2025年利润增幅不能直线外推。2026Q1营收下降4.60%，归母净利增长6.91%，扣非增长4.28%，经营现金流增长23.97%，经营改善尚算扎实。

2025年经营现金流6.90亿元，购建长期资产现金支出2.24亿元，简化FCF约4.66亿元；2024年对应约4.36亿元。2023年因房地产开发支出导致经营现金流仅1.37亿元，显示单年FCF会被营运资本显著扰动。2025年粗略ROIC按税后经营利润除以平均投入资本估算约8%—9%，略高于公司的低风险融资成本，但并非卓越回报生意。

2026Q1货币资金22.52亿元，应付债券4.99亿元，另有租赁负债和一年内到期非流动负债约0.51亿元，粗略净现金约17.0亿元；流动资产50.96亿元、流动负债17.50亿元。财务安全垫明显。公司无优先股或永续债，也未出现股本稀释。

分红方面，2025年中期及末期合计每股0.121元、总额1.58亿元，支付率30.09%。股息有覆盖但现价股息率仅2.19%，投资回报主要仍依赖盈利维持和估值修复，不能把它当高股息替代品。

## 最强正面证据与反面证据

最强正面证据是：2025年特种箱毛利率上升1.96个百分点至26.97%，毛利占比升至72.21%；2026Q1扣非利润与经营现金流继续增长，同时公司净现金约占市值24%。市场对低ROE国企的折价已有一定体现。

最强反面证据是：五年ROE仅约5%—7%，长期价值创造能力一般；2025年四季度归母亏损0.22亿元，利润季节性和年末减值波动明显；此外14.52亿元房地产存货占2025年末总资产14.1%，其中开发产品已计提1.91亿元跌价准备，仍是不能忽视的尾部风险。

其他主要风险：

1. 供应链贸易收入占比高、毛利不足1%，客户信用及商品价格波动可能造成应收或存货损失。
2. 铁路运价、清算机制和箱型投放受国铁体系政策影响，少数股东难以推动激进资本回报。
3. 沙鲅铁路依赖东北港口、大宗商品及钢铁产业链，公路和其他港口竞争会压制运量与价格。
4. 15.3万只特种箱需要持续更新，若扩张资本开支回报低于预期，账面净现金会变成低效资产而非股东价值。
5. 2025年联营企业投资亏损0.33亿元；非核心房地产、冷链和其他业务可能继续拖累。

## 模型选择、公式与输入

公司是盈利且拥有净现金的一般企业，采用 **FCFF DCF**；因贸易收入巨大而毛利极薄，收入倍数和EV/销售没有意义。PE可作交叉检查，但2024—2025减值波动会扭曲单年利润；P/B只用于检验资产折价，不能替代现金流估值。

公式：

- FCFF = EBIT ×（1－税率）＋折旧摊销－资本开支－营运资本增加
- 企业价值 = 明确期FCFF现值＋终值现值
- 股权价值 = 企业价值＋净现金－少数股东权益
- 每股价值 = 股权价值 ÷ 13.055亿股

为了避免把2026Q1的强现金流年化，模型从可持续FCFF出发。基准首年FCFF取4.7亿元，接近2025年简化FCF 4.66亿元；未来五年增长3.5%，WACC 9.5%，永续增长2.0%，低于折现率；Q1净现金取17亿元。少数股东权益仅0.21亿元，已在取整时覆盖。

概率加权价值 = 3.15×25%＋6.40×55%＋10.10×20% = **6.33元**。

熊市情景同时反映房地产继续减值、核心运量承压以及部分净现金被低效资本开支消耗；牛市情景要求特种箱投入持续带来高增量回报，不能作为主要买入依据。

交叉检查：以2025 EPS 0.402元计，5.52元对应13.7倍PE；若2026可持续EPS为0.50—0.58元，则仅9.5—11.0倍。Q1每股净资产约6.00元，现价0.92倍PB，但7%左右长期ROE决定其不应获得高PB。按2025分红的股利折现价值明显低于DCF，是因为支付率只有30%；它证明分红覆盖充足，却不能独立证明低估。

## 敏感性与反向估值

基准五年增速3.5%、永续增长2%、净现金17亿元不变：

| 首年FCFF / WACC | 9.0% | 9.5% | 10.0% |
|---|---:|---:|---:|
| 4.2亿元 | 6.18元 | 5.85元 | 5.57元 |
| 4.7亿元 | 6.77元 | 6.40元 | 6.07元 |
| 5.2亿元 | 7.35元 | 6.94元 | 6.58元 |

反向估值：5.52元对应市值约72.06亿元；扣除17亿元净现金后，市场隐含企业价值约55.1亿元。在WACC 9.5%、五年增长2.5%、永续增长2%的假设下，反推首年可持续FCFF约 **4.05亿元**。这个门槛低于2024—2025简化FCF 4.36—4.66亿元，却高于包含2023年地产开发现金流低谷后的保守长期均值。换言之，市场在定价“近两年现金流大部分可持续，但不相信明显增长”，并非定价业务崩塌。

按PB反推也得到类似结论：0.92倍PB若成本权益9.5%、长期增长2%，对应长期ROE约8.9%〔隐含ROE = PB×（Ke－g）＋g〕，高于2021—2025实际5%—7%。因此低于1倍PB并不是无条件便宜；需要2026Q1所显示的利润改善能把长期ROE推向8%—9%。

## 最终判断及失效条件

**最终分类：中度低估，较适合耐心等待更大安全边际的防守型观察仓。** 现价的净现金保护和核心特种箱壁垒是真实的，但ROE偏低、地产存货和低毛利贸易使其无法获得优质消费或平台型公司的估值。若价格降至5.0元附近而经营假设不变，基准安全边际约22%；若升至6.5元以上，则已接近基准价值，不宜再以“破净”作为买入理由。

以下任一情况会推翻中度低估判断：连续两个报告期扣非利润下滑超过15%；特种箱毛利率跌破23%；房地产和联营投资年度新增减值超过2亿元；净现金降至10亿元以下但核心FCFF没有提高；或中期FCFF持续低于4亿元。

## 下期重点监控

1. 特种箱发送量、单箱收入及毛利率，尤其26.97%的毛利率能否维持。
2. 沙鲅铁路到发量与铁路货运及临港物流毛利率（2025年15.00%）。
3. 扣非净利润与经营现金流是否继续同向增长。
4. 房地产存货14.52亿元的去化、售价和新增跌价准备。
5. 货币资金、公司债及新增特种箱资本开支，净现金是否被有效使用。
6. 年度现金分红支付率能否稳定在30%以上。

# 上海银行（601229）投资分析

更新日期：2026-08-11  
价格基准：2026-08-10收盘价9.27元  
投资期限：3—5年  
结论：**条件式小仓，合理价值约10.0—12.0元，风险加权基准约10.8元；表面上现价仅0.52倍最新PB、5.61%回顾股息率且2025年普通股ROE仍有9.69%，但200亿元上银转债几乎全部未转股，8.35元转股价低于现价。按完全转股压力口径，股本约增加16.9%、BVPS由17.81元摊薄至约16.44元，未来每股分红也会被摊薄。房地产不良率升至2.91%、零售不良率升至1.34%，关注率一季度仍约2.12%。现价有约14%的基准折价但不足以重仓；8.5元以下可分批，7.5元以下才有较强安全边际。**

## 估值快照：必须把转债摊薄放进分母

2026年6月末普通股约142.09亿股，9.27元对应现有普通股市值约1,317亿元。2025年归母净利润241.93亿元，扣除8.04亿元优先股股息后普通股利润约233.89亿元，基本EPS 1.65元，现价约5.6倍2025年普通股PE。2026年一季度归母净利润63.34亿元、增长0.66%，EPS 0.45元。

一季度末归母净资产2,630.24亿元，扣除100亿元优先股后普通股权益约2,530亿元，BVPS 17.81元，现价PB约0.521倍。这个静态指标没有体现转债潜在新增股本。

截至2026年6月末，199.77亿元上银转债尚未转股，占发行量99.89%；当前转股价8.35元。若全部转股，将新增约23.93亿股、股本增加16.8%，同时约200亿元债务转入权益。以一季度账面为起点，完全摊薄BVPS约为`（2,530+200）亿元÷166.0亿股=16.44元`，现价对应摊薄PB约0.564倍。

2025年度中期与末期分红合计每股0.52元，现价回顾股息率5.61%，分红占普通股净利润31.59%。若未来利润和分红总额不变而转债完全转股，每股股息机械降至约0.445元，前瞻股息率约4.8%。转股会补充核心资本并减少利息，却不能假定每股价值不受影响。

## 五年经营趋势：收入先降后修复，利润依靠低信用成本维持

2021—2025年收入累计下降2.6%，净息差下降58个基点，普通股ROE由11.80%降至9.69%；但普通股BVPS复合增长约7.4%，利润保持低个位数增长。低PB有息差下行的合理解释，尚未出现账面价值停滞。

2025年收入增长3.35%，利息净收入增长2.64%，净息差仅降1个基点至1.16%；存款平均成本下降约40个基点至1.52%，是息差企稳主因。非利息净收入增长4.48%，成本收入比下降至23.31%。利润增长2.69%慢于收入，表面上并未依赖少提全部拨备粉饰增长。

但过去几年拨备垫持续消耗：拨备覆盖率由2021年的301.13%降至244.94%，拨贷比由2023年的3.29%降至2025年的2.89%。2025年不良生成率约1.42%，同比上升约40个基点，而贷款减值准备余额下降6.56%。利润稳定与拨备下降需要合并看待。

2026年一季度收入增长4.25%，利息净收入增长5.08%，归母利润仅增长0.66%。市场测算单季净息差约1.08%、同比略升，负债成本继续下降；但拨备覆盖率又降至241.30%。核心收入恢复是积极信号，利润弹性尚未得到确认。

## 资产质量：总不良稳定，地产与零售风险抬头

2025年末客户贷款1.44万亿元、增长2.49%，不良率连续两年下降后稳定在1.18%，拨备覆盖率244.94%。逾期贷款238.33亿元、占比1.65%，较上年下降0.08个百分点；逾期90天以上贷款与不良贷款之比94.20%，分类审慎度尚可。

关注类占比由年中2.04%升至年末约2.11%，2026年一季度约2.12%；已重组贷款由39.54亿元升至51.08亿元、占比由0.28%升至0.35%。关注和重组并未失控，但方向弱于静态不良率。

公司贷款不良余额115.58亿元、减少1.87亿元，不良率由1.37%降至1.35%；其中房地产却逆向恶化，不良余额由11.65亿元升至36.01亿元，不良率由0.98%升至2.91%，主要来自存量个案下迁。房地产贷款约占总贷款8.6%，还需与按揭和其他涉房资产合并压力测试。

个人贷款不良率由1.14%升至1.34%；按揭不良率升至0.69%，个人经营贷不良率升至2.39%。零售不良生成同比下降是正面迹象，但不良存量与比率尚未见拐点。上海房价与就业环境好于多数低能级城市，不能据此免除抵押物和借款人现金流风险。

## 资产结构、区域与资本

上海银行扎根上海，并覆盖长三角、京津冀、粤港澳和成渝重点城市。养老金客户AUM超过5,000亿元、上海养老金代发客户份额领先，老龄金融和本地对公结算构成存款壁垒。2025年存款仅增长1.43%，企业活期存款下降约4.4%，负债成本改善更多来自存款重定价而非低成本存款量快速扩张。

贷款结构中泛政信类约占27.5%，为最大单一板块。公开披露没有统一、可直接核验的地方融资平台贷款口径，因此本报告不编造城投敞口；地方国企和公共项目的信用质量、期限及化债后的低利率仍应作为整体ROE约束。

2025年末核心一级资本充足率10.65%，一季度升至10.73%，明显好于北京银行等资本紧张同业。若转债全部转股，核心资本会进一步增加约200亿元，资本安全性改善；这正是“公司更安全、现有每股价值被摊薄”的交换。

年末优先股账面100亿元，年度股息8.04亿元。普通股BVPS和EPS已扣除优先股影响，估值口径无误。债权投资规模大且历史非标资产透明度低于标准债券，不过公司持续压降非标，2025年中期债权与其他债权投资第三阶段金额合计较小；未来仍需核对资产管理计划、信托计划的阶段二迁徙和减值。

## 完全摊薄后的剩余收益估值

银行采用简化稳定期剩余收益模型：合理PB约等于`（长期ROE－长期增长）/（股权成本－长期增长）`。基准以完全转股后的16.44元BVPS为起点，再施加潜在信用损失折扣。

| 情景 | 账面价值压力折扣 | 长期ROE / 股权成本 / 增长 | 压力后BVPS | 每股价值 |
|---|---:|---:|---:|---:|
| 悲观 | -15% | 4.5% / 13.0% / 0% | 13.97元 | 约4.8元 |
| 基准 | -5% | 8.5% / 11.5% / 1.0% | 15.62元 | 约11.2元 |
| 乐观 | 0% | 10.0% / 10.5% / 2.0% | 16.44元 | 约15.5元 |

悲观情景假设地产、零售、政信及非标资产合计造成约410亿元摊薄后普通股权益损失，ROE降至4.5%；基准情景假设约137亿元压力损失、息差仅温和修复，长期ROE降至8.5%；乐观情景要求负债成本改善延续、风险指标回落且ROE维持10%。

对悲观、基准、乐观分别赋予25%、60%、15%权重，风险加权值约10.2元。考虑转债并非必然一次性全转、资本改善与模型误差，给出 **10.0—12.0元** 合理区间、约10.8元基准价值。现价相对基准仅约14%折价，不足以忽略悲观情景，所以只能小仓。

## 强制反向估值

反向估值一：按当前17.81元BVPS，9.27元对应0.521倍PB；按完全摊薄16.44元BVPS，则为0.564倍。若股权成本11%、长期增长1%，完全摊薄价格反向隐含长期ROE约 **6.64%**，比2025年9.69%低约3个百分点，市场已定价ROE继续下滑，但没有表面PB显示得那么悲观。

反向估值二：若长期ROE为基准8.5%，合理PB约0.714倍。当前价格要成立，相当于先把摊薄BVPS由16.44元削减到约12.98元，即隐含约575亿元、21%的转股后普通股权益永久损失。该金额大于年末约416亿元贷款减值准备，却并非远超不良加关注贷款，安全垫存在但不极端。

反向估值三：现有股本每股0.52元分红对应5.61%回顾收益率；若转债全转且分红总额不变，摊薄后每股约0.445元、收益率约4.80%。按11%股权成本和2%股息增长，摊薄股息折现价值约4.94元。其余价值依赖留存利润能否维持高于资金成本的ROE。

## 优势、风险与价格纪律

优势：上海及长三角客户和养老金业务具备存款壁垒；五年BVPS持续增长，2025年息差基本企稳；不良率1.18%、拨备覆盖率241%；核心一级资本充足率10.73%，转股后还会提升；现金分红比例升至31.59%。

风险：转债潜在股本摊薄约16.9%；净息差仅1.16%，长期盈利弹性有限；房地产不良率升至2.91%、零售不良升至1.34%；关注率和重组贷款上升；拨备覆盖和拨贷比连续下降；泛政信占比较高，化债有信用保护也会压低定价。

分类：**B级条件式小仓；历史第四批第55家公司完成深度更新，累计跟踪数不重复增加，暂列全局27D。** 排名明显低于沪农商行，核心原因是转债摊薄、地产不良和更低息差；资本与区域基础又优于高尾部风险区域银行。

| 股价 | 判断 |
|---:|---|
| 6.5元以下 | 接近压力价值，先排查是否发生地产或信用事件 |
| 6.5—7.5元 | 较强安全边际，可分批研究 |
| 7.5—8.5元 | 条件式买入区间 |
| 8.5—9.8元 | 观察性小仓，现价所在区间 |
| 9.8—10.0元 | 基本进入合理区间下沿，不宜新增 |
| 10.0—12.0元 | 合理价值区间 |
| 12.0元以上 | 需息差和零售地产质量持续改善支撑 |

## 失效条件与跟踪项

若总不良率升破1.5%、房地产不良率升破4.5%、关注类占比连续两期高于2.6%、拨备覆盖率跌破200%、核心一级资本充足率跌破10%，或完全摊薄后每股年度分红低于0.40元且非监管要求所致，应暂停加仓并重估。

重点跟踪：上银转债转股与赎回条款执行；完全摊薄EPS/BVPS和分红；地产、按揭、经营贷不良及核销；关注和重组贷款；净息差与企业活期存款；泛政信资产定价；债权投资中资管与信托计划的阶段二、三余额及减值。

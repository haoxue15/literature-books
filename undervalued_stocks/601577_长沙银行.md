# 长沙银行（601577）投资分析

更新日期：2026-08-11  
价格基准：2026-08-10收盘价9.22元  
投资期限：3—5年  
结论：**条件式小仓，合理价值约10.5—13.0元，风险加权基准约11.5元；现价约0.50倍最新普通股PB，反向只隐含约6.3%的长期ROE，相对2025年11.24%的加权ROE已计入明显下滑，具备约20%的基准安全垫。湖南县域存款壁垒、280%以上拨备和4.66%回顾股息率提供支撑；但2025年净息差下降26个基点、个人业务分部转亏、个人贷款不良率升至2.43%，关注类贷款又在2026年一季度增加8.11亿元。8.5元以下可分批，7.8元以下安全边际较强；现价只适合能承受区域银行信用尾部风险的分散小仓。**

## 估值快照：便宜，但不是无条件便宜

总股本约40.22亿股，9.22元对应市值约370.8亿元。2025年归母净利润81.08亿元，扣除优先股和永续债分配后的普通股利润77.60亿元，基本EPS 1.93元，现价约4.8倍2025年普通股PE。2026年一季度归母净利润22.99亿元、同比增长5.77%，EPS 0.57元；季度利润不能简单年化，但经营尚未失速。

2026年一季度末普通股BVPS 18.35元，现价PB约0.502倍。公司另有90亿元永续债，已从普通股权益中剔除，因此这里没有把其他一级资本误算给普通股股东。

2025年度中期和末期现金分红合计每股0.43元，按9.22元计回顾股息率4.66%；分红占普通股净利润22.28%。2023—2025年度每股分红由0.38元增至0.42元、0.43元，现金回报稳定，但派息率偏低意味着折价收敛仍主要依靠账面价值复利。

2021—2025年收入复合增长约5.1%，归母利润复合增长约6.5%，普通股BVPS复合增长约9.7%。增长质量却在2025年发生变化：收入下降1.79%，利息净收入下降6.12%，净息差从2.11%降至1.85%；归母利润增长3.59%，部分依靠信用减值损失由88.05亿元降至79.89亿元和管理费下降4.20%。利润增长慢于贷款扩张，也不能把少提拨备当作永久盈利能力。

收入结构同样提示压力。2025年公司业务收入127.39亿元、利润总额69.82亿元；个人业务收入94.32亿元、利润总额却由上年的盈利5.73亿元转为亏损4.04亿元；资金业务利润总额由17.87亿元升至34.17亿元。资金业务缓冲了零售风险，但投资收益和公允价值变动随市场波动，确定性低于净利息收入。

2026年一季度收入71.93亿元、增长5.64%，归母利润增长5.77%。净利息收入增长约2.17%，手续费净收入小幅下降；投资收益减少约4.16亿元，而公允价值变动由亏损约6.26亿元转为盈利约1.21亿元，约7.47亿元的摆动显著贡献收入增长。因此总收入改善不能全视为核心息差反转，需等半年报披露净息差验证。

## 资产质量：不良率稳定，零售和关注类先行指标恶化

2025年末贷款6,116.85亿元、增长12.21%；不良贷款约70.47亿元，不良率由1.17%降至1.15%，拨备覆盖率280.86%。逾期率1.66%，较上年下降0.14个百分点，表面资产质量稳健。

但关注类贷款由143.17亿元升至179.49亿元，增加36.32亿元、增幅25.4%，占比由2.63%升至2.93%。2026年一季度关注类进一步升至187.61亿元，单季增加8.11亿元；占比降至2.90%只是因为贷款增长更快。不良贷款余额同期也由约70.47亿元增至74.41亿元。关注加不良约262亿元，占贷款约4.05%，与3.23%的拨贷比相比并非没有缓冲，却不支持把1.15%的静态不良率当成风险见底。

结构风险集中在个人贷款。2025年个人贷款余额1,871.77亿元、下降1.23%，个人贷款不良率由2023年的1.52%、2024年的1.87%升至2.43%，对应不良余额约45.5亿元、增长约28.6%；公司贷款不良率仅0.61%。个人业务分部转亏与零售不良抬升互相印证，消费、经营和按揭贷款的迁徙率比总量指标更值得关注。

公司贷款增长17.56%至4,073.09亿元，增量超过600亿元。年末最大十家客户贷款占资本净额38.03%，较2024年的30.20%明显上升；单一最大客户占比也升至6.29%。大客户集中尚在监管范围内，但贷款增长向公司端倾斜后，地方国企、基建及产业客户的集中度和定价能力需持续审视。

## 湖南区域、负债与资本

长沙银行的核心优势是湖南本地网络和县域覆盖：它是湖南首个实现县域全覆盖的地方法人银行，2025年县域存款余额2,633.27亿元、增长12.45%。个人定期存款增长17.47%至3,404.71亿元，为流动性和客户黏性提供支撑。

代价是区域分散不足。公司绝大部分网点和贷款位于湖南，仅有广州等少量省外布局；湖南地方财政、地产、居民就业和产业周期会同时影响公司与零售信贷。区域化债可降低短期违约概率，也可能通过低息置换压低贷款收益率。现有公开年报没有给出可直接核验的统一口径地方融资平台贷款总额，因此本报告不编造精确“城投敞口”。

2025年末核心一级资本充足率10.05%，一季度回升至10.18%；资本充足率由13.95%升至14.01%。资本缓冲够用但不宽裕，远弱于拨备覆盖率给人的表面安全感。2025年风险加权资产增长6.62%，慢于贷款增长，未来若风险权重或信用成本上升，内生资本补充仍是约束。

公司2025年赎回60亿元优先股，但期末仍有90亿元永续债。普通股BVPS和ROE已扣除其他一级资本影响，估值口径正确；不过永续债分配、较低派息率以及可能的资本工具发行都会延缓普通股价值兑现。公司股东会材料还涉及延长公开发行可转债相关决议有效期，应把潜在摊薄视为待核实风险，而不能在尚未发行前直接扣减股本。

## 压力后剩余收益估值

银行不适合用工业企业自由现金流估值。本报告使用简化稳定期剩余收益模型：合理PB约等于`（长期ROE－长期增长）/（股权成本－长期增长）`，并先对18.35元BVPS施加潜在信用损失折扣。

| 情景 | 账面价值压力折扣 | 长期ROE / 股权成本 / 增长 | 压力后BVPS | 每股价值 |
|---|---:|---:|---:|---:|
| 悲观 | -15% | 4.5% / 13.0% / 0% | 15.60元 | 约5.4元 |
| 基准 | -8% | 8.5% / 11.5% / 1.0% | 16.88元 | 约12.1元 |
| 乐观 | 0% | 11.0% / 10.5% / 2.0% | 18.35元 | 约19.4元 |

悲观情景假设零售、区域企业和贷款外信用资产合计造成约111亿元普通股权益损失，长期ROE降至4.5%；基准情景假设约59亿元压力损失、净息差继续低于历史且长期ROE降至8.5%；乐观情景要求零售风险回落、息差稳定并保持当前附近ROE。

对悲观、基准、乐观分别给30%、55%、15%权重，风险加权值约11.2元。考虑区域银行尾部风险、资本补充和模型误差，给出 **10.5—13.0元** 合理区间、约11.5元基准价值。现价相对基准约有20%折价，却仍显著高于5.4元悲观值，所以应依靠分散和买入纪律，而非集中押注均值回归。

## 强制反向估值

反向估值一：9.22元除以18.35元BVPS，市场PB约0.502倍。若股权成本11%、长期增长1.5%，市场反向隐含长期ROE约 **6.27%**；若股权成本11.5%、增长1%，隐含ROE约6.28%。这比2025年11.24%的实际ROE低近5个百分点，说明市场已定价息差和信用成本显著恶化。

反向估值二：若长期ROE能保持本报告基准的8.5%，在11.5%股权成本和1%增长下合理PB约0.714倍。以现价倒推，市场相当于先把18.35元BVPS削减至约12.91元，即隐含约219亿元、29.6%的普通股权益永久损失。该损失约为年末贷款损失准备197.91亿元的1.1倍，也接近一季度关注加不良贷款余额；定价悲观，但并非极端到可以忽略隐藏风险。

反向估值三：每股0.43元股息对应4.66%回顾收益率。按11.5%股权成本和2%长期股息增长，股息折现值约4.62元。现价高于单纯股息价值，是因为约78%的普通股利润被留存并增加账面价值；若长期ROE低于股权成本，低派息会使折价长期存在。

## 优势与反方证据

优势：

1. 0.50倍最新普通股PB和约4.8倍2025年PE已计入显著盈利下滑。
2. 五年普通股BVPS复合增长近10%，2026年一季度收入和利润继续增长。
3. 不良率1.15%、拨备覆盖率281%，当前损失吸收能力仍较强。
4. 湖南县域全覆盖和本地存款基础构成区域壁垒，个人定期存款增长较快。
5. 每股0.43元分红对应4.66%回顾股息率，分红连续增长且利润覆盖充分。

反方证据：

1. 2025年净息差下降26个基点、利息净收入下降6.12%，营收五年来首次负增长。
2. 个人业务分部由盈利转为亏损，个人贷款不良率升至2.43%。
3. 关注类贷款2025年增加36.32亿元，一季度又增加8.11亿元。
4. 利润增长部分依靠减值少提；一季度收入改善又含较大的公允价值变动摆动。
5. 公司贷款快速扩张，最大十家客户集中度明显上升，湖南区域风险难以分散。
6. 核心一级资本充足率约10.2%，资本缓冲不算宽裕，仍有90亿元永续债。
7. 普通股派息率仅22.28%，价值兑现速度慢；潜在可转债可能造成稀释。

## 分类与价格纪律

分类：**B级条件式小仓；历史第四批第64家公司完成深度更新，累计跟踪数不重复增加，暂列全局27C。** 排名低于渝农商行和沪农商行，原因是零售不良、关注类和资本缓冲更弱；排名高于贵阳银行，原因是盈利能力、拨备与区域经济基础相对更好。

| 股价 | 判断 |
|---:|---|
| 6.5元以下 | 接近极端压力价值，应先核验是否发生资产质量突变 |
| 6.5—7.8元 | 较强安全边际，可在风险指标稳定时分批 |
| 7.8—8.5元 | 可建立条件式小仓 |
| 8.5—9.8元 | 观察性小仓，现价所在区间 |
| 9.8—10.5元 | 折价有限，等待更好价格 |
| 10.5—13.0元 | 合理价值区间，不追价 |
| 13.0元以上 | 需息差稳定、零售风险回落和ROE维持两位数支撑 |

## 失效条件与下一报告期跟踪

若出现以下任一情况，应暂停加仓并重做压力测试：个人贷款不良率升破3.2%，关注类占比连续两个季度高于3.5%，总不良率升破1.6%，拨备覆盖率跌破230%，核心一级资本充足率跌破9.5%，或年度每股分红降至0.35元以下且不是监管要求所致。

重点跟踪：

1. 个人消费、经营、按揭贷款的不良率、逾期率和迁徙率。
2. 关注类贷款余额是否连续下降，而不只是占比被贷款增长稀释。
3. 净息差、净利息收入和存款成本能否在半年报稳定。
4. 公司贷款增量行业、前十大客户集中度及地方化债置换定价。
5. 信用减值损失、核销处置和利润增长之间的桥梁。
6. 资金业务利润中投资收益、公允价值变动和债券处置的可持续性。
7. 核心一级资本、永续债分配及可转债方案的发行进度与摊薄比例。
8. 2026年中期分红是否延续，以及全年派息率能否提高。

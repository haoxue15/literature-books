# 渝农商行（601077）投资分析

更新日期：2026-08-11  
价格基准：2026-08-10 A股收盘价6.46元  
投资期限：3—5年  
结论：**值得分批研究，合理价值约8.5—10.5元，基准约9.5元；6.5元附近已有较清晰安全边际，5.8元以下更理想。现价约0.54倍最新普通股PB、约6倍正常化PE，反向只隐含约6.6%的长期ROE；而2025年普通股ROE约9%、不良率1.08%、拨备覆盖率367.26%，2026年一季度净息差回升至1.69%、归母利润增长5.07%。折价并非无因：重庆区域集中、零售不良率升至2.07%、金融投资快速扩张和60亿元永续债均需监控，但目前披露证据没有显示这些风险足以解释近半账面折价。**

2021—2023年收入连续下降，但归母利润连续增长，说明早期盈利改善部分来自信用成本下降；2024—2025年收入恢复正增长，质量较前两年更好。2025年利息净收入242.61亿元、增长7.85%，存款付息率下降28个基点至1.45%，负债成本下降基本抵消资产收益率压力；手续费净收入下降19.71%、其他非息收入下降25.55%，收入结构仍有短板。

2026年一季度收入增长8.39%，利息净收入增长15.08%，净息差由2025年全年1.60%升至1.69%，成本收入比降至22.40%；信用减值损失反而增长16.21%，归母利润仍增长5.07%。这比单靠少提拨备的利润增长更扎实，但单季息差受存款重定价和资产扩张影响，仍需半年报确认。

## 资产质量与区域风险

2025年末贷款7,972.87亿元、增长11.62%，不良率下降10个基点至1.08%，关注类和逾期贷款占比分别降至1.42%和1.19%。一季度贷款再增长4.11%，不良率继续降至1.07%，拨备覆盖率仍为365.72%。这些指标显著优于贵阳银行，也优于多数农商行整体水平。

风险从对公转向零售：2025年公司贷款不良率由1.04%降至0.55%，零售贷款不良率却由1.60%升至2.07%；年末按揭、消费贷（含信用卡）和经营贷不良率约1.60%、2.61%和1.97%。零售不良贷款中有较高比例具备抵质押或保证，能降低最终损失率，但消费贷增长23.01%时资产质量同步恶化，需要防止以放量掩盖新生成。

银行业务高度集中重庆，县域存贷款市场份额居当地同业首位。区域壁垒带来超过8,800亿元个人存款和低成本资金，也把重庆地产、区县财政及地方平台风险集中在同一资产负债表。公司没有在简要披露中给出可直接核验的统一城投贷款余额，因此本报告不编造精确敞口；投资者应持续从建筑、租赁商务、公共设施行业贷款及重组、展期数据交叉验证。

2025年中房地产业公司贷款约58亿元，占总贷款不到1%，直接开发贷不大；但按揭、抵押经营贷以及地方建设项目会形成更广义地产关联风险。重庆化债降低短期违约概率，也可能通过低息置换压低未来贷款收益率。

## 资本、金融投资与分红

一季度末归母权益1,419.66亿元，其中永续债59.98亿元；扣除后普通股权益约1,359.69亿元，普通股BVPS 11.97元。现价PB约0.540倍。核心一级资本充足率由年末12.67%降至12.25%，资本充足率由14.46%降至14.00%，仍有缓冲，但一季度风险加权资产增长7.92%，快于资本增长，扩表速度不能长期高于内生资本补充。

一季度金融投资由6,436.30亿元升至7,229.47亿元，增长12.32%，占总资产约41%。其中债权及其他债权投资为低风险债券的重要载体，但交易性金融资产和利率波动会影响非息收入与其他综合收益。2025年其他非息收入下降正说明债市收益不能视作稳定票息。

2025年中期加末期合计每股分红0.32091元，合计36.45亿元、占归母利润30.05%；按6.46元计股息率约4.97%。派息率明显高于贵阳银行，且中期分红降低价值实现等待时间，但60亿元永续债还会优先承担利息，普通股估值必须使用扣除永续债后的权益和利润。

## 压力剩余收益估值

以一季度普通股BVPS 11.97元为起点，使用稳定期剩余收益关系`合理PB=（长期ROE－g）/（Ke－g）`，并在悲观和基准情景先对账面价值施加信用损失折扣。

| 情景 | 账面压力折扣 | 长期ROE / Ke / g | 每股价值 |
|---|---:|---:|---:|
| 悲观 | -10% | 6.5% / 11.5% / 1.0% | 约5.6元 |
| 基准 | -3% | 9.0% / 10.5% / 2.0% | 约9.6元 |
| 乐观 | 0% | 10.5% / 10.0% / 2.5% | 约12.8元 |

悲观情景已同时假设约136亿元普通股权益损失、ROE降至6.5%；基准ROE略低于近年正常水平，以反映零售风险与化债压价。综合模型误差，合理区间取 **8.5—10.5元**，基准约9.5元。现价相对基准折价约32%，同时仍高于悲观值约15%，适合分批而非一次性重仓。

## 强制反向估值

反向一：现价PB约0.540倍。以10.5%股权成本、2%长期增长计算，市场隐含长期ROE约 **6.59%**，较2025年约9%的普通股ROE低约2.5个百分点，也低于一季度年化水平。

反向二：若长期ROE能维持9%，合理PB约0.824倍。当前价格相当于先把普通股BVPS从11.97元削减至约7.85元，即隐含约468亿元、34%的普通股权益永久损失；这远高于当前不良贷款88.67亿元，即使把关注贷款和零售风险纳入也属于较重压力预期。

反向三：0.32091元分红对应4.97%收益率。在10.5%股权成本、2%永续增长的股息模型中价值约3.85元。股息模型偏低是因为只分配约30%利润；只要留存利润能维持高于6.6%的ROE，新增账面价值仍在创造价值，反之低派息会放大价值陷阱风险。

## 优势、风险与价格纪律

优势：县域存款壁垒强；资产质量和拨备优于多数区域银行；收入与息差已出现修复；分红率提升至30%；现价反向预期明显低于实际盈利能力。

主要风险：重庆区域和地方财政集中；零售不良率上升；消费贷快速扩张；金融投资占比较高；资本充足率随扩表下降；A股价格通常高于H股，跨市场投资者应比较折价后再选类别。

分类：**B+级值得分批研究；由历史第四批第66名升级为全局20B，累计公司数不增加。**

| A股价格 | 判断 |
|---:|---|
| 5.6元以下 | 接近压力悲观价值，资产质量未恶化时可优先复核 |
| 5.6—6.5元 | 具备安全边际，可分批研究；现价所在区间 |
| 6.5—7.5元 | 合理偏低，需确认零售不良见顶 |
| 7.5—8.5元 | 折价收窄，持有优于追买 |
| 8.5—10.5元 | 合理价值区间 |
| 10.5元以上 | 需ROE回升至两位数支撑 |

失效条件：零售不良率升破3%、整体不良率升破1.5%、拨备覆盖率跌破300%、核心一级资本充足率跌破11.5%，或净息差重新跌破1.5%且拨备前利润下降。
